# ASR 学习框架（对照真实字幕 ASR 管线）

目标不变，但对象从「玩具脚本」换成「你们生产字幕链路的迷你版」：

1. 能复现：指标 / 对齐 / VAD / 方案A / 后处理能在本仓库稳定跑出同样数字
2. 能解释：CER 56% 但 IoU precision 90% 意味着什么，该查哪一层
3. 能决策：Belle-only vs Paraformer+FA vs 强过滤，以及要不要上 Qwen-Audio-3.0

## 目录

00_admin        规划、自查、**生产管线对照表**
01_metrics      CER/WER + 语言瓶颈拆解（Week 1-2）
02_srt          SRT 规范 / CPS / origin vs asr 段统计（Week 1-2）
03_alignment    IoU 匹配、漏段诊断、DTW、**方案A 文本级 FA**（Week 1-2 & 7-8）
04_audio        16k PCM、能量 VAD、Mel、SpecAugment 直觉（Week 3-4）
05_inference    CTC vs Attention、解码消融、幻觉检测（Week 5-6）
06_papers       Whisper / WhisperX / Paraformer / Calm-Whisper / Qwen3-ASR
07_training     热词词典、SpecAugment、领域适配（Month 4-5）
08_engineering  自适应路由、Profiling、学习版 Gateway+报表页（Month 6）
lib             被上面课程共用的实现（对照生产模块）
pipeline        一键质量报告 = 生产「ASR report page」的学习版
data/srt        origin.sample.srt / asr.sample.srt（真实样本，不是玩具句）
results         实验导出

## 闭环

1. 最小脚本跑通
2. baseline vs 改动
3. 结果落到 `asr_learning/results/`
4. 用 `00_admin/每周自查清单.txt` 验收
5. 打开 `asr_learning/results/asr_report.html` 讲给别人听
