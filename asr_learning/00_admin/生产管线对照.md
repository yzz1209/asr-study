# 生产管线对照

本云端仓库**拿不到**内网 `172.30.48.30` 上的工程源码，但 `1_ASR学习路径.pdf` 和 `origin.sample.srt` / `asr.sample.srt` 已经把真实字幕 ASR 写死了。下面用你们自己的词（Belle、Paraformer、方案A、Gateway、报表页、Qwen-Audio-3.0）把学习代码一一对上。

## 生产链路（影视字幕）

```
视频音轨
  → 转封装 PCM 16 kHz / 16bit / mono
  → VAD（生产：Silero；学习：能量阈值）
  → 双模型 ASR
        Belle / Whisper 系（Attention，文本更好，易幻觉，时间戳差）
        Paraformer / FunASR（NAR+CTC，时间轴准，幻觉形态不同）
  → 对齐
        A2 垂直路径 = 方案A：Belle 文本 ⊕ Paraformer 字级时间戳（字符串匹配 / LCS）
        备选：WhisperX wav2vec2 CTC Forced Alignment
  → 后处理
        BoH 短语、VAD 交叉、avg_logprob / no_speech_prob、n-gram 重复、attention 熵
        热词 / 领域词（人名地名、玄幻专名）
  → Gateway 出 SRT
  → 报表页：CER + IoU P/R + 偏移/漂移 + 幻觉列表（给编辑出片）
```

样本轨已经暴露生产形态：

| 信号 | 样本上的数字 | 生产含义 |
| --- | --- | --- |
| origin 段数 | 223 | 内挂/人工字幕，对白更全 |
| asr 段数 | 116 | 模型漏了大约一半 cue |
| CER（去空白） | ≈ 56% | 删除 572 vs 替换 102 → **漏识别是主因** |
| Alignment precision | ≈ 90.5% | ASR 段大多能对上 origin，乱切不多 |
| Alignment recall | ≈ 47% | **漏段**；先查 VAD / 配乐 / 模型吞词 |
| 起始偏移中位数 | ≈ -85 ms | 整体略早，还不像严重漂移 |

这就是「CER 25% 但 IoU 47%」那道题的真实版本：文本错和轴错是两件事，必须拆开看。

## 一份样本里能看见的「语言瓶颈」

origin 有、asr 经常写飞的词（同音/近音）：

- 灵相 / 灵想，灵皇境 / 灵黄镜，大荒 / 大包
- 镇灵司 / 镇宁寺，南陵城 / 南临城，符技 / 福击
- 化重如羽 / 化中如云

这不是随机 CER。这是领域词表没进解码。生产讨论里的 language bottleneck 就是这件事。

## A2 垂直路径

PDF 任务 8 把「不用 WhisperX、只用字符串把 Belle 文本对齐到 Paraformer 词时间戳」叫作方案 A。学习仓把它实现为 `scheme_a_report()`，在报表里叫 **A2-text-forced-alignment**。

若你们内网 A2 还包含 Gateway 路由或其它竖切，以对照表为索引：先在本仓库跑通文本 FA，再回生产源码看同一条数据路径。

## 明确做不到的

- 不在本仓库加载 Belle / Paraformer / Qwen 权重（无 GPU、也不把生产模型塞进学习仓）
- 解码消融用 `mock_decoder` 只保证**指标方向**（升温更易幻觉、greedy 更易替换）
- 真实 15 轨测试集、Gateway 鉴权、报表页前端不在这里；用 HTML 学习版代替
