怎么读这份报告

  • CER(去标点)=50.6% 而时间轴 recall=47.1% / precision=90.5%。 CER 高 + recall 低 = 漏了大段对白，不是单纯同音错字。
  • 漏段：origin 大量段没被 ASR 覆盖（VAD 过猛 / 模型吞词 / 切段粒度差）
  • 漂移：偏移随时间变大，优先查分段累计误差 / 变声变速 / FA 失败
  • 语言层瓶颈候选热词：先歇歇脚、内生乾坤、力破神庭、十二灵宫、可谁料到、周天既成、天行有常、封灵止煞
  • 方案A MeanErr=295ms（PDF 门槛 800ms，达标）
  • 字面对得上但轴对不上 6 条（切段/IoU，不是幻觉）；真幻觉候选 4 条（无 origin 文本或 BoH/重复）。
